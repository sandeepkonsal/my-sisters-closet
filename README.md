# My Sister's Closet

Curated pre-loved fashion — website concept, built as a static multi-page site.

## Pages
- `index.html` — Home
- `pages/closet.html` — The Closet (shop grid + filters)
- `pages/sell.html` — Sell With Us
- `pages/about.html` — About
- `pages/lookbook.html` — Lookbook
- `pages/journal.html` — Journal
- `pages/contact.html` — Contact

## Stack
Plain HTML/CSS/JS. No build step. Fonts: Playfair Display (headings), Inter (body), Dancing Script (accent). Palette: black `#0b0b0b`, cream `#f6ebc2`, pink `#e63e82`.

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy
Enabled via GitHub Pages on the `main` branch (root).
